PHOTOS FOR THE WEBSITE
======================

1) Landing-page squad photo  ->  save as:  club-team.jpg
   The home page hero looks for images/club-team.jpg automatically.
   This is the COMPETITION SQUAD photo (captioned "Our competition squad"),
   not all club members. If the file is missing a placeholder is shown.
   Recommended: landscape, around 1200x900px (4:3).

2) Logo  ->  save the OFFICIAL logo as:  warsc-logo.png
   The site uses images/warsc-logo.png if present (the real club logo with
   the skater + infinity ribbon), and falls back to warsc-logo.svg (a close
   recreation) if the PNG is missing.
   TIP: a version with a TRANSPARENT background (or trimmed of black padding)
   looks best in the header/footer. A square PNG works fine too.

Only publish photos you have consent to share (see Photo & Media Consent).
